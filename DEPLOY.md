# DarkPhilosophy — Portfolio

Live site (after GitHub Pages deployment): https://darkphilosophy.github.io/DarkPhilosophy/

The root README renders on GitHub. The static portfolio is stored in `site/` and is deployed via `.github/workflows/pages.yml`, with no build step.

If GitHub Pages has not previously been enabled, open **Settings → Pages → Build and deployment → Source: GitHub Actions**, save, then re-run the **Deploy DarkPhilosophy portfolio** workflow. This publishing workflow needs Pages write and ID-token permissions.

This separate portfolio does not overwrite AXXA.dev. It contains conceptual previews for Timehacker and Project Pandorium (not actual gameplay captures). The Peersus demo is a visual mockup, not a file transfer or encryption implementation.
